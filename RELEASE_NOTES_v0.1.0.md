# FlowTS v0.1.0

First public release.

## Highlights

- Native Windows GUI.
- Embedded TeamSpeak client bot mode using TSLib.
- No ServerQuery bot and no external TS3AudioBot process.
- Updates the bot nickname from the current foreground application.
- Supports TeamSpeak domain names and ports.
- Tray background mode.
- Start with Windows in background mode.
- Auto connect option.
- Dev Mode debug log toggle.
- Fixed-size windows to keep layout stable.
- Self-contained Windows x64 single-file executable.

## Download

Use:

```text
FlowTS-v0.1.0-win-x64.zip
```

Extract it and run:

```text
FlowTS.exe
```
