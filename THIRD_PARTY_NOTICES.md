# Third-party Notices

FlowTS includes or references the following third-party components.

## TS3AudioBot / TSLib

FlowTS vendors `TSLib` from the open-source TS3AudioBot project under:

```text
vendor/TS3AudioBot-source/
```

The upstream license files are preserved in:

```text
vendor/TS3AudioBot-source/LICENSE
vendor/TS3AudioBot-source/LICENSE_COMPLETE
```

## libopus

FlowTS includes `libopus.dll` for TeamSpeak client audio library compatibility:

```text
vendor/libopus/libopus.dll
```

The Opus license files included with TSLib are preserved in:

```text
vendor/TS3AudioBot-source/TSLib/Audio/Opus/LICENSE
vendor/TS3AudioBot-source/TSLib/Audio/Opus/OPUS_LICENSE
```
